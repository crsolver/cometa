# DUNGEON.mode

Original, unmodified bitmap atlases by **datagoblin**:
https://datagoblin.itch.io/dungeonmode

The author distributes this pack under **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/

`dungeon-437.png` supplies text and extended ASCII characters;
`dungeon-mode.png` supplies fantasy icons. Each contains 256 8×8 cells
in a 16×16 grid. Character mappings follow the pack's Playscii `.char` files.
The compiler bundles both atlases for `std/pincel/retro`; generated programs
do not need external asset files.
